# Tic Tac Toe

A Flutter Tic Tac Toe game targeting Android and Web.

**Owner:** FullStackShack  
**Package:** com.fullstackshack.tictactoe  
**Flutter:** 3.41.4 | **Dart:** 3.11.1

## Getting Started

```bash
flutter pub get
flutter run -d chrome       # Web
flutter run -d <device-id>  # Android
```
