# Tic Tac Toe

Classic Tic Tac Toe by **App Verse Games**: play the computer (Easy, Medium, Hard), a friend
on the same device, or watch two computers play and explain every move (Watch and Learn).

- **Package:** `com.appversegames.tictactoe`
- **Platforms:** Android (main, with AdMob ads), web (embedded on appversegames.com), Windows.
  iOS is set up but not tested yet.
- **Shared code:** depends on `../appverse_core_kit` (theme, settings, ads, sound, Watch and
  Learn), so keep both folders side by side in `D:\Development`.

## Run

```bash
flutter pub get
flutter run -d windows      # Windows app (home page, app bar)
flutter run -d chrome       # Web build (opens straight into the game)
flutter run -d <device-id>  # Android
```

## Test

```bash
flutter analyze
flutter test
```

## Build and deploy the web version

From PowerShell in the project folder (not Git Bash, which rewrites `/play/...`):

```powershell
.\tool\build_web.ps1
```

This builds with `--base-href /play/tictactoe/ --no-web-resources-cdn` and writes
`build\tictactoe-web.zip`. Extract it into `public_html/play/tictactoe/` on the server so
`index.html` and `.htaccess` sit directly in that folder, then check
`https://appversegames.com/play/tictactoe/`.

The WordPress page `/games/tictactoe/` (parent **Games**) uses this Custom HTML block:

```html
<div class="avg-embed" data-src="/play/tictactoe/" data-title="Tic Tac Toe"></div>
<script src="/play/tictactoe/embed.js" defer></script>
```

## Layout

```
lib/game/      rules, setup, controller, AI and demo commentary (no widgets)
lib/screens/   home, game, Watch and Learn, how to play
lib/widgets/   board, cells, scores, dialogs, Games Hub, play-time bar
lib/services/  Sign in with Google, page visibility (web embed)
tool/          build_web.ps1, generate_icons.py, generate_sounds.py
```

Sounds and icons are generated by the Python scripts in `tool/`; see
[assets/ASSETS.md](assets/ASSETS.md). Before publishing, follow
[docs/admob_setup_guide.md](docs/admob_setup_guide.md) for real AdMob IDs.
